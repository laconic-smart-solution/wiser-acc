# WISER ACC Corporate Website Project Plan

## Project Overview
A premium static corporate website for WISER ACC, an authorized overseas factory of Shanghai WISER Group.

## Goals
- Build brand trust
- Showcase machinery and hotel linens
- Generate B2B inquiries
- Support SEO and mobile devices

## Sitemap
1. Home
2. About Us
3. Products
4. Solutions
5. Projects
6. Contact

## Design Style
- Minimal, elegant, premium
- White background with deep blue accents
- Large photography and generous whitespace

## Tech Stack
- HTML5
- Tailwind CSS
- Vanilla JavaScript
- EmailJS/FormSubmit
- Vercel or Netlify hosting

## Deliverables
- Responsive website
- Image gallery
- Downloadable catalog
- Contact form
- Basic SEO

- Logo (SVG)
